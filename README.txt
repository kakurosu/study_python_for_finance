============================================================
 Study Python for Finance — セットアップ手順 (Windows)
============================================================

このアプリは「Python と uv だけインストールされていれば
動く」ように作られています。PyInstaller のような重い実行
ファイルではなく、ソース + ロックファイルを配布する形です。

------------------------------------------------------------
 1. 必要なもの
------------------------------------------------------------
 - Python 3.11 以上
     https://www.python.org/downloads/
 - uv (Python パッケージマネージャ)
     PowerShell で次を実行:
       powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
     インストール後、新しいターミナルを開き直すと `uv` が
     PATH に通っていることを確認できます:  `uv --version`

------------------------------------------------------------
 2. 配布物の展開
------------------------------------------------------------
 受け取った ZIP を任意のフォルダに解凍してください。
 OneDrive 同期フォルダなどパス長制限のある場所より、
 例えば C:\study_python_finance\ などのトップ近くを推奨。

------------------------------------------------------------
 3. (任意) Proxy 環境の場合
------------------------------------------------------------
 社内ネットワークで proxy 経由のアクセスが必要な場合のみ:

   1) `.env.example` をコピーして `.env` というファイル名にする
   2) `.env` を開き、HTTPS_PROXY 行の先頭の `#` を外して
      自分の環境の proxy URL に書き換える
      例:  HTTPS_PROXY=http://proxy.example.com:8080

 Proxy が要らなくなったら、その行の頭に `#` を戻すか
 行ごと削除すれば、次回起動から通常モード（直接接続）に戻ります。

 ※ proxy が不要な環境では `.env` を作らなくても問題ありません。

------------------------------------------------------------
 4. 起動
------------------------------------------------------------
 `run.bat` をダブルクリックしてください。

 初回起動:
   - 依存パッケージ (PyTorch / Playwright / Streamlit など
     合計 1.5-2 GB) をダウンロード・インストール
   - 数分〜十数分かかります（ネットワーク速度次第）

 2 回目以降:
   - 数秒で起動します（既にダウンロード済み）

------------------------------------------------------------
 5. 動作確認
------------------------------------------------------------
 起動するとダッシュボードが表示されます。

   - 章を選んで演習を進める
   - 設定画面でテーマ（ダーク / ライト）を切替
   - 学習履歴は `progress.db` に保存されます

 困ったとき:
   - logs\app.log にエラーログ
   - 学習履歴をリセットしたい → 設定 → 学習履歴を初期化
   - 依存パッケージを再取得したい → `.venv` フォルダを削除して
     再度 run.bat を実行

------------------------------------------------------------
 6. (応用) 共有フォルダで複数人で使う場合
------------------------------------------------------------
 ファイルサーバや OneDrive 共有にこのフォルダを置いて
 複数人で使うとき、1 人が初回に取得した依存パッケージ
 (1.5-2 GB) を他の人が再利用できるようにするには:

   1) .env.example を .env にコピー
   2) UV_CACHE_DIR の行のコメント # を外し、共有フォルダの中の
      任意の場所を指す
        例: UV_CACHE_DIR=\\fileserver\share\study_python\uv_cache
   3) UV_PROJECT_ENVIRONMENT の行も # を外し、各ユーザーの
      ローカルに .venv を作るよう設定
        例: UV_PROJECT_ENVIRONMENT=%USERPROFILE%\.study_python_venv

 この設定で、A さんが初回 run.bat 実行で共有キャッシュに
 ダウンロード → B さんが run.bat 実行すると共有キャッシュから
 数十秒で .venv が組み上がります（ネットワーク帯域を消費しません）。

 注意:
  - 共有フォルダの .venv そのものを使い回すのは NG
    (絶対パス問題・ファイルロックで破損するため)
  - キャッシュは共有 / .venv はユーザー個別、が正解
  - OneDrive 同期フォルダはファイルロック問題があるため、
    UV_CACHE_DIR は OneDrive 配下を避けてください
